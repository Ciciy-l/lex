01 / Workspace

One work surface. Every useful context stays close.

一块工作面，所有关键上下文都在手边。

Lex uses Cindy's original content tabs instead of building a second workspace. The tool rail navigates; the main area is where work opens and continues.

Lex 复用 Cindy 原有内容页签，不再制造第二个内容区。工具区负责导航，主内容区负责打开并延续工作。

01.1 / SAME CONTENT AREA

Conversation beside a capable workbench

主对话旁，是一套完整工作台

Terminal, files, browser, Worker conversations and Review open as normal content tabs. Files, background tasks, collaboration and Git remain available from the fixed tool rail.

终端、文件、浏览器、Worker 对话和审查都在原内容区打开；文件、后台任务、协同和 Git 则留在固定工具区随时导航。

02 / Open lineage

Built on Cindy.
Shaped as Lex.

基于 Cindy，
形成 Lex 自己的方向。

The boundary is part of the product, not fine print. Lex owns the community desktop experience; Cindy continues to provide the online services users choose at sign-in.

这不是藏在角落里的小字，而是产品边界本身：Lex 负责社区桌面体验；登录时选择的在线服务继续由 Cindy 提供。

Lex is independently maintained and is not affiliated with or endorsed by XD Inc. or Cindy. Cindy services follow Cindy's own terms, availability and support. One Lex installer serves all users; the signed-in account determines its service region.

Lex 由社区独立维护，与 XD Inc. 或 Cindy 不存在隶属、授权或官方背书关系。Cindy 服务遵循其官方条款、可用性与支持政策。Lex 始终只有一个安装包，由登录账号决定所用服务区。
