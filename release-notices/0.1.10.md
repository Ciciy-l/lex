# Lex 0.1.10

2026-10-24

Lex 0.1.10 改善长对话滚动、GUI/TUI 切换和本机 Codex 协同体验。

- **更顺畅的长对话**：改善长对话的滚动响应与历史消息浏览。
- **常驻切换底栏**：GUI/TUI 切换、工作目录和用量集中在底部；切换视图时按钮位置不变，保留各自尚未发送的输入。
- **清楚的准备状态**：首次打开原生终端时显示准备状态；等待期间选择 GUI，不会被稍后完成的准备切回 TUI。
- **本机 Codex 协同**：Lead 和 Worker 可切换 GUI/TUI，支持 Worker 焦点切换与窗口间输入接管；TUI 中也能看到待处理事项入口。
- **直接进入隔离任务**：新建 worktree 任务时可直接打开 TUI，沿用所选工作目录、模型和权限。
- **更方便的终端**：新增终端搜索与字号调节，并修复独立窗口中 Worker 输入区域可能无法显示的问题。

不同引擎的可用操作以当前任务提示为准；SSH 任务暂不提供 TUI 切换。

Android 请使用完整 APK 直接覆盖安装，请勿先卸载。桌面安装包的实际签名状态以发行页为准；暂不提供 iOS 安装包。
