# Lex 0.1.5-rc.1

本次预发布选择性合入 Cindy v0.1.104 的修复与优化，建议桌面和 Android 一同更新。

- 修复任务权限恢复、SSH 与设备连接、Pi 切模和断线处理，完善四引擎模型偏好保存。
- 改善手机登录恢复、已发送消息显示、模型选择、语音输入、历史滚动与长任务性能。
- 持久保存任务图片，手机输入框支持选择已安装插件。
- 完善当前引擎的 MCP 工具发现、异步提问和 Pi 子代理控制。
- 四引擎新增生成速度与等待状态展示，完成后可回看本轮结果。
- 优化 OMP/Pi 设置布局，修正桌面二维码的 Lex 下载入口。

此版本仅进入 beta 更新渠道，正式版仍为 0.1.4。可开启“接收测试版更新”或下载对应安装包；Android 沿用原包名和签名，可覆盖升级。
