# Lex 0.1.5

2026-10-14

本次正式版改善任务稳定性、手机体验、Git 侧栏与引擎设置，建议桌面和 Android 一同更新。

- **任务与远控更稳定**：修复任务权限恢复、SSH 与设备连接、Pi 切模和断线处理，完善异步提问与 Pi Subagent 的等待、停止和继续操作。
- **手机消息与图片更可靠**：改善登录恢复、已发送消息、历史滚动、语音输入和长任务阅读；任务图片持久保存，输入框可选择已安装插件。
- **四引擎速度可回看**：显示首响应等待、生成、工具执行和重试状态，完成后保留速度图表与输出结果。
- **关闭使用统计，优化启动画面**：强制关闭 Lex 客户端 TapDB 使用统计；桌面启动背景加载更轻，手机启动人物、字标与加载提示布局更清晰。
- **Git 与协同侧栏更顺手**：工作目录内可发现和切换多个仓库；单行 Graph 前置 HEAD 与分支，文件状态用颜色和字母区分；侧栏可直接创建 Worker，无内容页签时自动收起空白区域。
- **引擎设置更紧凑**：OMP 压缩阈值支持百分比滑杆和原生默认，准确标识实际模型协议；设置说明更简短，修复 Pi 官方版本检测与升级失败提示。
- **更新四引擎默认版本**：Claude Code 2.1.296、Codex 0.162.1、Pi 1.2.0、OMP 18.10.4。保留已显式选择的引擎版本，也可在设置中恢复 Lex 基线。

正式版与 beta 用户均可升级至 0.1.5，也可从 [Lex 下载页](https://ciciy-l.github.io/lex/) 或 [本版安装包](https://github.com/Ciciy-l/lex/releases/tag/v0.1.5) 安装。Android 保持原包名 `io.github.ciciyl.lex` 和永久签名，可直接覆盖安装，请勿先卸载。暂不提供 iOS 安装包。
