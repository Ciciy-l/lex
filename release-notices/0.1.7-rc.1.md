# Lex 0.1.7-rc.1

2026-10-20

Lex 0.1.7-rc.1 预发布版改善桌面 Codex 任务的 GUI/TUI 切换与取消后继续输入。

- **从 TUI 开始**：新建未命名 Codex 任务后，可在左侧对话区底部选择 TUI，直接发送第一条消息，无需先在 GUI 发送。
- **继续同一任务**：通过底部 GUI/TUI 切换，共享同一任务与对话记录，来回切换后可继续输入。改善当前窗口内的草稿保留、输入焦点和累计用量显示；已接收的输入只交接一次。
- **取消后继续**：取消当前生成后，可回到原 TUI 明确发送新消息；未发送的草稿保留，状态不明的输入不会自动重发。

## 已知限制

Windows 本机实测首次冷恢复历史约需 14 秒，其他环境耗时可能不同。本次切换实测使用本地模拟模型；其他引擎、macOS/Linux、真实供应商与高级工具未逐项实测。GUI/TUI 的可用功能仍有差异。
