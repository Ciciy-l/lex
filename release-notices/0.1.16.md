Lex 0.1.16 新增任务上下文窗口与原生区域截图，并带来 Orca 派单上下文策略和更稳的供应商设置。

- **任务上下文窗口**：任务状态栏新增上下文窗口预算与用量控制，可按任务查看和调整可用窗口；模型限制在刷新模型列表后仍会保留。
- **原生区域截图**：新增系统级区域截图流程，截图窗口可保存或复制到任务；账号切换与窗口归属变化时会取消或隔离未完成的截图。
- **供应商设置**：自定义模型连接改为按协议分页，并支持逐条设置模型 ID；渠道探测与连接测试更稳定，刷新后不会丢失已选模型限制。
- **Orca 派单上下文**：派发 Worker 时可选择保留、清空或压缩上下文。目标正在清空或压缩时，新派发会得到明确的“操作完成后重试”提示，不再静默排队；清空后的历史可在派发对话框内以可读文本查看。
- **稳定性修复**：附件下载停滞会明确失败而不是一直等待；改进 Windows 项目路径处理、容量类错误分类、Claude Code 在已有输出后不再静默停止，以及弹窗路由。
- **安装须知**：Android 使用完整 APK 覆盖安装，不要先卸载。iOS 仍需自行签名安装，签名到期独立于版本更新；更换签名身份、bundle ID 或卸载可能影响数据，请先备份。桌面签名与公证状态以发行页为准。
