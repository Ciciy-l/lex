Lex 0.1.12 改善终端恢复、消息引用与文件链接，新增 GPT Fast 选项并完善 Codex 压缩。

- 终端添加菜单移除旧的 Agent CLI 快捷启动入口，保留 Shell、远程终端与浏览器；项目主页同步介绍现有 GUI/TUI 工作台。
- 恢复终端时，仍在运行的终端继续重连；确认旧终端已不存在时自动恢复对应 Shell 和工作目录，无需反复手点重启，也不会重放之前输入的命令。
- 新增 GPT Fast 选项。在模型自定义设置中主动开启，默认关闭；可用性由当前模型、连接和引擎决定，可能额外计费，实际处理档位以服务端为准。
- 完整引用不再重复加入同一条消息正文，长引用优先保留所引用消息，并控制最终发送大小。
- 明确的文件链接在暂时失效时仍保留入口，显示失败原因，支持刷新重试；远程链接继续在对应电脑上解析。
- Codex 支持手动原生压缩，在兼容连接上优先尝试服务端压缩，自动压缩仍由原生运行时管理。确认可安全回退时使用同模型摘要；TUI 任务失败时保留当前任务并提示。结果未知时不自动重复压缩，重新打开任务后可按当前连接再次尝试。
- 模型请求使用 Lex 应用标识，保留原生客户端信息、必要协议字段和显式自定义请求头。

Android 请使用完整 APK 覆盖安装，请勿先卸载。桌面安装包的实际签名与公证状态以发行页为准；暂不提供 iOS 安装包。
