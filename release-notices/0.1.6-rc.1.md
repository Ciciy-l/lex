# Lex 0.1.6-rc.1

2026-10-14

本次预发布版改善模型连接配置与桌面、手机的模型选择。

- **多协议、多渠道**：供应商配置按协议组织，同一协议可添加多个具名渠道，分别保存连接地址、密钥和模型。
- **同名模型，明确来源**：同一供应商的同名模型合并展示，可展开选择具体渠道和自动或固定协议；模型能力、窗口和价格跟随实际选择。
- **手机与电脑同步选择**：手机可选择渠道和协议，电脑确认后才应用切换；收藏保留具体来源。
- **连接方式更清楚**：OMP 增加原生 Google Gemini 协议选项。Claude Code 与 Codex 使用其他协议时明确显示为 Lex 桥接。
- **保留已有配置**：已有连接、密钥、收藏和模型设置保留原选择，OAuth、订阅、Vertex 与 Bedrock 仍有专用配置入口。
- **右侧工具栏靠右**：内容尚未加载或已隐藏时，右侧栏工具按钮仍保持在右边。
