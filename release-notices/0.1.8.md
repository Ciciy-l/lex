# Lex 0.1.8

2026-10-23

Lex 0.1.8 为 Android 带来 Lex Server 登录，并改善桌面登录导航、模型选择和手机输入的稳定性。

- **Android 登录服务**：可选择 Lex Server、Cindy 或免登录进入，支持保存、恢复、切换和退出账号；不同服务的账号互不影响。
- **顺畅的桌面登录**：修复 Lex Server 重新登录进入错误页面的问题；从登录服务选择页返回时，不再重复显示“Lex正在唤醒”。
- **精简模型选项**：模型名称与上下文容量同行显示，选项更紧凑。
- **更稳定的手机输入**：修复手机连续输入时可能报错的问题，并改善返回应用后的草稿恢复。
- **Codex 任务启动**：修复部分 Codex 任务无法启动的问题。

## 升级须知

Android 需下载完整 APK，直接覆盖安装即可，请勿先卸载。桌面安装包的实际签名状态以发行页为准；暂不提供 iOS 安装包。
