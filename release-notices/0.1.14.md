Lex 0.1.14 新增 Cindy 任务导入，并改善模型选择与 Fast 操作。

- 桌面端任务导入新增与 Codex、Claude Code 并列的 Cindy 来源，支持分组、勾选与批量导入。仅导入常规任务，自动排除伙伴及伙伴群聊相关记录。请先退出源 Cindy，再扫描并预检；导入会创建独立副本，不修改源数据。缺失的历史或附件会在确认前提示，原有登录凭证不会导入。
- 修复 GUI 输入框下方模型名称过早折叠的问题：空间足够时显示更多名称，仅在工具栏拥挤时截断。
- 桌面和移动端在模型选择右侧新增闪电开关，无需展开模型配置。开关与模型配置同步，按当前引擎和模型能力显示；实际速度、可用性及计费由供应商决定。

Android 请使用完整 APK 覆盖安装，不要先卸载。桌面安装包实际签名与公证状态以发行页为准；暂不提供 iOS 安装包。
