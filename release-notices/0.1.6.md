# Lex 0.1.6

2026-10-16

Lex 0.1.6 正式版改善模型连接、任务连续性和手机操作，并移除伙伴相关功能。

- **多协议、多渠道**：供应商按协议配置，可为同一协议添加多组地址、密钥和模型。同名模型保留具体渠道，桌面和手机按电脑确认的实际来源切换。OMP 支持原生 Gemini；Claude Code、Codex 的其他协议连接明确标注 Lex 桥接。已有专用供应商设置继续保留。
- **模型与任务连续性**：自动切换避免跨 Codex 协议混用历史，思考档位优先保留实际运行值。改善 Pi 上下文缓存、定时任务恢复与排队图片保留。
- **连接与查询**：修复部分供应商返回无类型标头的事件流时，非流式请求得到异常结果的问题。Agent 查询定时任务支持按关键词筛选，并明确查询范围为当前电脑。
- **手机与界面**：改善后台切换、重连历史保留和隐藏弹层的开销；停止生成后可删除消息，收到电脑确认后才更新列表。右侧工具栏保持靠右，供应商配置交互继续优化。
- **伙伴功能退休**：移除伙伴、伙伴私聊、伙伴群聊及专属定时流程的入口与运行功能。旧资料保留在原存储中，不自动删除、不继续执行，也不转成普通任务；本版不提供其浏览和导出入口。普通任务、Orca 协作、定时任务、Skills、插件及 IM 接入继续可用。
