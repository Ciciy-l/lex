# Lex 0.1.7-rc.2

2026-10-21

Lex 0.1.7-rc.2 预发布版改善桌面四种 Agent 引擎的主要 GUI/TUI 交互，并支持重启后恢复已保存的草稿。

- **同一任务，切换继续**：Claude Code、Codex、Pi 与 OMP 的本地新任务可直接从原生 TUI 发送首条消息；GUI/TUI 来回切换沿用原任务与对话记录。停止生成后可明确发送新消息，状态不明的输入不会自动重发。
- **草稿跨重启恢复**：原任务与新任务分别保存草稿；已保存的文本、附件和图片批注可在桌面端重启后恢复，发送或丢弃后清理。
- **引擎状态与用量**：修正 Pi 正常空闲退出被误报为异常的问题，改善 OMP 真实消息用量的累计显示，重新打开任务不重复累加。

## 已知限制

OMP 原生任务暂时关闭自动 recap，规避已观察到的空闲断连；显式 TUI 设置仍可能重新开启。`/btw`、`/omfg` 与其它辅助并发未验，不代表所有原生辅助功能已对齐。

本次交互实测使用 Windows 专有模拟模型，真实供应商、macOS/Linux 与高级工具未逐项实测。GUI/TUI 可用功能仍有差异。草稿恢复针对已保存内容，尚未保存的最后编辑不保证在硬中断后恢复。
