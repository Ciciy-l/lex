Lex 0.1.11 完善本机 GUI/TUI 输入、历史分支与协同体验。

- Pi、OMP 响应期间可从 GUI 追加正文，并更准确地跟踪排队、消费和停止状态。Pi 原生任务的 GUI 正文统一按文本发送；原生命令、模板与输入扩展请在 TUI 中使用，Lex 已有命令保持可用。
- Pi 可在历史中切换或另存分支，OMP 可另存所选历史分支后继续当前任务。切换保留未发送内容；中断恢复不会自动重发结果未知的输入。
- 本机 Pi、OMP、Claude Code 的 Lead/Worker 可使用原生终端，完善派单、排队、中断和回报衔接。原有权限审批保持有效。
- Claude Code 空闲任务切换模型时保留原历史、未发送内容和用量，修复退出协同后旧身份可能在设置重开时残留的问题。
- 改善终端大段粘贴、搜索键盘操作和焦点恢复；隐藏 Worker 面板后，不再迟到弹出创建窗口。
- Mac DMG 拖拽安装窗口改用 Lex 品牌背景。

不同引擎的设置与追加能力仍有差异，以当前任务可用操作为准；Claude Code 不提供同轮追加，Pi/OMP 协同消息在忙时采用排队或显式中断。SSH 任务暂不提供 TUI 切换。

Android 请使用完整 APK 覆盖安装，请勿先卸载。Mac 背景更新不改变签名或公证状态，实际安装包签名信息以本发行页为准；暂不提供 iOS 安装包。
