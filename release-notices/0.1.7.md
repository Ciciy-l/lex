# Lex 0.1.7

2026-10-21

Lex 0.1.7 正式版整理模型选择与可选登录流程，并汇总桌面端主要 GUI/TUI 交互和草稿恢复改进。

- **更清晰的模型选择**：模型名称优先展示，渠道与协议合并为一处紧凑入口，保留原有选项；长名称可查看完整提示。
- **打开即可使用**：未登录时默认进入主界面；主动登录先选择账号服务（本轮仅 Cindy），再进入现有登录流程，取消可返回。已登录账号仍正常恢复，在线能力继续遵守原登录与权限要求。
- **同一任务，切换继续**：Claude Code、Codex、Pi 与 OMP 的本地新任务可直接从原生 TUI 发送首条消息；GUI/TUI 切换沿用原任务与历史。停止后可明确发送新消息，状态不明的输入不会自动重发。
- **草稿跨重启恢复**：原任务与新任务分别保存草稿；已保存的文本、附件和图片批注可在桌面端重启后恢复，发送或丢弃后清理。
- **引擎状态与用量**：修正 Pi 正常空闲退出被误报为异常，改善 OMP 真实消息用量显示，重开任务不重复累计。

## 已知限制

OMP 原生任务暂时关闭自动 recap，规避已观察到的空闲断连；显式 TUI 设置仍可能重新开启。`/btw`、`/omfg` 与其它辅助并发未验，不代表所有原生辅助功能已对齐。GUI/TUI 可用功能仍有差异。

引擎交互实测使用 Windows 专有模拟模型，真实供应商、macOS/Linux 与高级工具未逐项实测。草稿恢复针对已保存内容，尚未保存的最后编辑不保证在硬中断后恢复。
