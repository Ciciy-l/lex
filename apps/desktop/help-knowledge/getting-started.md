title: Getting started with Lex
summary: Create a session, choose an agent and working directory, send your first prompt, and iterate.
---
Lex is a community desktop app based on Cindy that runs AI coding agents (Claude Code, Codex, and Pi) for you.

**Your first session:**

- Click **+ New** in the top of the left sidebar.
- Choose the **agent** (Claude Code or Codex).
- For code work, choose a **working directory** — the agent runs its file ops there. (You can skip this for plain-Q&A sessions.)
- Optionally pick a **model** in the composer toolbar.
- Type your goal and send.

**Iterating:**

- A session is a persistent chat thread: ask, review the result, then ask the next thing.
- While the agent is replying, the **Send** button becomes **Stop** — click it to interrupt. You can keep typing in the meantime; follow-ups queue up and send in order.
- Type `/` in the composer to open the slash-command palette (see the Commands topic).

**Organizing:**

- All sessions are listed in the left sidebar (see the Sidebar topic). Switch between them by clicking; each session remembers its agent, model, and working directory.
- Keep unrelated tasks in **separate** sessions — sharing one session for everything dilutes context.

**Tone tip:**

- Describe the goal and context first, then what result you want. That works better than a single short command. The agents respond well to "here's what I'm trying to do, here are the constraints, here's what 'done' looks like".
